# Склад кафе

Приложение для телефона (PWA): отчёт смены, склад, график, журнал. Сайт лежит на GitHub Pages, данные в Supabase.

## Как устроено
- `index.html`: всё приложение. `config.js`: адрес и публичный ключ Supabase, ссылка на Google Таблицу с графиком.
- `sw.js`: сервис-воркер. Сайт берётся из сети, кэш нужен только без интернета. После правок поднимайте номер `CACHE`, тогда телефоны обновятся сами.
- Нажатия без интернета сохраняются на телефоне и уходят сами, когда связь вернётся (даже если приложение закрыли).
- Изменения с других телефонов приходят через Supabase Realtime за секунду. Запасной опрос базы раз в 5 минут.

## Автоматика
| Что | Когда | Где |
|---|---|---|
| Вечерняя сводка в Telegram, если отчёт за день не сдан | 23:00 МСК | Supabase, pg_cron (`cafe-evening-report`) |
| Пинг базы, чтобы бесплатный проект не уснул | 12:00 МСК | GitHub Actions, `.github/workflows/daily_cron.yml` |
| Пустой коммит раз в 50 дней, чтобы GitHub не выключил расписание | при пинге | тот же workflow |

Секреты в GitHub не нужны: адрес и публичный ключ workflow берёт из `config.js`.
Проверить вручную: вкладка Actions -> Daily ping -> Run workflow.

## База (Supabase)
1. SQL Editor -> New query: вставьте весь `schema.sql`, Run. Это безопасно, данные не пропадут.
2. `products.sql` (после schema.sql) заводит список товаров. В первый день: Склад -> «Пересчитать склад».
3. Аккаунты создаёт `create_accounts.sql`. Этот файл с паролями НЕ загружайте на GitHub.
   Регистрации в приложении нет: в Supabase выключите Authentication -> Sign In / Providers -> "Allow new users to sign up".

## Telegram-бот
1. В Telegram откройте @BotFather -> /newbot, получите токен.
2. Гарик (или группа, куда добавлен бот) пишет боту любое сообщение.
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}`. Это chat id (у групп с минусом).
4. В приложении: Кабинет -> Dev-панель -> Telegram-бот: токен и chat id, Сохранить, Тест.
5. Если тест не пришёл, нажмите «Ответ Telegram»: там будет ошибка от Telegram.

## Важно
- Токен бота хранится только в базе, телефоны работников его не видят.
- Dev-панель видят только роли «Разработчик», база тоже отказывает всем остальным.
- Раз в неделю в Dev-панели скачивайте бэкап базы.
