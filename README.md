# Склад кафе v4: что сделать после обновления

## 1. Сайт (GitHub)
1. В репозитории загрузите заново `index.html` и `sw.js` (Add file -> Upload files).
2. Создайте файл `.github/workflows/daily_cron.yml` (Add file -> Create new file, в имени файла наберите путь целиком) и вставьте содержимое.
3. Телефоны сами подтянут новую версию при следующем открытии. Если какой-то телефон застрял на старой, закройте приложение и откройте снова.

## 2. База (Supabase)
1. SQL Editor -> New query: вставьте весь `schema.sql`, Run. Это безопасно, данные не пропадут.
2. Скрипт сам назначит роли по логинам: `ilya`, `arsen` -> разработчик, `garik` -> владелец, `tatyana` -> админ.
   Сработает только для уже зарегистрированных аккаунтов. Если логины другие, поправьте их внизу schema.sql.
   Если кто-то из них ещё не зарегистрирован, пусть зарегистрируется, потом запустите schema.sql ещё раз.
3. Старые товары разложатся по цехам по ключевым словам (один раз). Дальше цех меняется в карточке товара.

## Товары
`products.sql` (SQL Editor -> Run, после schema.sql) заводит весь список товаров. Остатки у считаемых товаров стоят 0:
в первый день откройте Склад -> «Пересчитать склад», впишите реальные числа и сохраните.

## Аккаунты
Регистрации в приложении нет. Все аккаунты создаёт `create_accounts.sql` (SQL Editor -> Run, после schema.sql).
Этот файл с паролями НЕ загружайте на GitHub. В Supabase выключите Authentication -> Sign In / Providers -> "Allow new users to sign up".

## 3. Telegram-бот
1. В Telegram откройте @BotFather -> /newbot, получите токен.
2. Гарик (или группа, куда добавлен бот) пишет боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}`. Это chat id (у групп с минусом).
4. В приложении: Кабинет -> Dev-панель -> Telegram-бот: вставьте токен и chat id, Сохранить, Тест.
5. Если тест не пришёл, нажмите «Ответ Telegram»: там будет ошибка от Telegram.

## 4. Ежедневный пинг и вечерняя сводка (GitHub Actions)
1. Dev-панель -> GitHub Actions -> «Создать секрет» -> «Копировать».
2. В репозитории: Settings -> Secrets and variables -> Actions -> New repository secret, три секрета:
   - `SUPABASE_URL`: как в config.js
   - `SUPABASE_ANON_KEY`: как в config.js
   - `CRON_SECRET`: скопированный секрет
3. Вкладка Actions -> Daily ping and evening report -> Run workflow: проверьте, что всё зелёное.
4. Каждый день в 21:00 по Москве база получает пинг (проект не уснёт), а если отчёт за день не сдан, Гарику уходит сводка.

## Важно
- Токен бота хранится только в базе, телефоны работников его не видят.
- Dev-панель видят только роли «Разработчик». Гарик её не видит, база тоже отказывает всем остальным.
- Раз в неделю в Dev-панели скачивайте бэкап базы.
